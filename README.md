# レッスン帳（LessonManage）

ボイトレ・バイオリンなどのレッスンを記録する iOS アプリ。Expo（React Native）で作っている。

- 要件：`docs/requirements.md`
- 決めたこと：`docs/adr/`
- 画面の試作：`design/prototypes/`（採用案は `g1-toggle.html`）

## 動かし方

```bash
npm install
npx expo start
```

iPhone の Expo Go で、表示された QR コードを読み取る。

## 確認

```bash
npm run typecheck
```
