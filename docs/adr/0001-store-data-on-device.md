# 0001 データは端末の中だけに保存する

- 状態：採用（2026-11-16）

## 決定

レッスン・曲・メモ・録音のデータは、すべて iPhone の中だけに保存する。サーバーやクラウドへの同期は作らない。

## 理由

サーバー代や運用の手間をかけたくないため。録音は1回40〜50分になり、クラウドに置くと容量と費用がかさむ。

## 影響

- ログインやサーバーは不要
- バックアップはアプリでは扱わない。機種変更や端末の故障には、iOS の設定（iCloud バックアップなど）で備える（本人が決めたこと）
- 録音が端末の容量を圧迫する
- PCなど iPhone 以外からは見られない
