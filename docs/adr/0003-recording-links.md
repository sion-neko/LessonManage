# 0003 録音は「どのレッスンの後か」と「どの曲か」をそれぞれ任意で持つ

- 状態：採用（2026-11-16）

## 決定

録音は1種類のデータとして持ち、「どのレッスンの後か」と「どの曲か」を、それぞれ任意で参照する。

| 録音の種類 | レッスン | 曲 |
|---|---|---|
| レッスンの録音 | そのレッスン | なし |
| 個人練の録音 | どのレッスンの後か（ホームや曲ページから録ると直近のレッスン。前のレッスンのページから録る・取り込む・録音を直すシートで、ほかのレッスンにも付けられる） | 弾いた曲（任意） |
| レッスンと関係ない録音 | なし | その曲 |

レッスンのページの「このレッスン後の個人練」と曲ページの「録音」は、どちらもこの参照から一覧を作る。

## 理由

個人練で曲を指定したときは、1回録れば、レッスンのページと曲ページの両方に出したい。録音をレッスン用と曲用に分けて持つと、同じ演奏を二重に録るか、片方にしか出ないことになる。

個人練は曲を弾くとは限らない（スケールや基礎練習など）。そのため、曲とのつながりはユーザーが曲を指定したときだけ作り、自動では付けない。

## 影響

- 個人練の録音を消すと、レッスンのページと曲ページの両方から消える
- 曲を消しても、その曲の個人練の録音は曲なしとしてレッスンのページに残る。レッスンと関係ない録音は、どこにも出なくなるので一緒に消える
- 曲ページから録った録音は、既定でそのフォルダの直近のレッスン後の個人練になる（外すとレッスンと関係ない録音になる）
