# 要件

ボイトレ・バイオリンなどのレッスンを記録する iOS アプリ。

楽譜は前提にせず、「レッスン → 個人練 → 次のレッスン」のサイクルを記録して振り返れるようにする。

画面の試作は `design/prototypes/`（採用案は `g1-toggle.html`）。

## 前提

- iOS アプリ（iPhone）
- データは端末内だけに保存する
- まずは自分用

## 画面

下のタブは「いま」「レッスン」「曲」の3つ。フォルダ（バイオリン、ボイトレなど。習いごとごとに1つ作る入れ物）が2つ以上あるときだけ、各タブの上にフォルダの切り替えを出す。1つのときは出さない。

レッスンを2つ以上習っている人は少ないため、1つを前提にして画面をすっきりさせる。フォルダを選ぶ画面を手前に挟む案もあるが、毎回1タップ増えるのでとらない。

### いま（ホーム）

選んでいるフォルダの、直近のレッスンを1画面で表示する。

- 「練習すること」：宿題を色付きの枠の中に大きく表示する。枠の上に、そのレッスンの日付（例：11/17（月））だけを出す
- 学んだこと：先生の指摘も自分の気づきもすべて、題ごとに並べる。見出しはつけず、先生と自分は行の左の線の色で分ける
- レッスンのページへのリンク：色付きの枠の右上、日付の横に置く（個人練の一覧はレッスンページで見る）
- 「個人練を録音」のボタン：画面下に固定する（宿題が多くても隠れないように）。設定でオン・オフできる（既定はオン）。ホームから録音するかどうかは人によって大きく分かれるので、出さない選択もできるようにする

ホームは、宿題・学んだこと・個人練を同じ強さで並べると、どこを見ればいいか分からなくなる。いちばん大事な宿題だけを色付きの枠で目立たせ、ほかは控えめにする。

レッスンがまだないフォルダでは、「最初のレッスン」ボタンを出す。

### 最初の起動とフォルダの管理

- 初回は、習っているもの（フォルダ）と先生・教室を入れる画面から始める
- フォルダの追加、名前と先生の変更、削除、ホームの録音ボタンのオン・オフは、画面右上の歯車から行う
- フォルダを削除すると、そのフォルダのレッスン・曲・録音もすべて消える。削除する前に、消える件数を出して確かめる

「今週」ではなく「直近のレッスン」にしているのは、バイオリンとボイトレでレッスンの頻度が違い、間隔が空いても表示が消えないようにするため。

### レッスンページ

レッスン1回につき1ページ。

| 項目 | 内容 |
|---|---|
| フォルダ | ユーザーが自分で追加できる（例：バイオリン（ブライアン先生）） |
| 日付 | |
| 扱った曲 | 曲ページへのリンク。複数可 |
| レッスン録音 | アプリ内で録音する |
| 学んだこと | 題ごとに、1行1項目の箇条書き。各行に「先生（先生の指摘）」か「自分（自分の気づき）」の印をつけ、タップで切り替える。新しい行は先生が既定 |
| 宿題 | 1行1項目の箇条書き。チェック機能はなく、メモとして書く |
| このレッスン後の個人練 | 日付・録音・一言のセットを積み重ねる |

学んだことは「題」ごとにまとめて書く。題は、扱った曲（例：♪ ユーモレスク）か、自由な言葉（例：手首が固まってしまう）のどちらか。

- 「＋ 題を追加」で、扱った曲を選ぶか、言葉を入れて題を作る。各題の下に、その題の追加欄がある
- 題をタップすると、名前を変えたり題を外したりできる（外した題の行は題なしに戻る）
- 題のない行も書ける（題をまだ作っていないレッスンでは、すべて題なしの行になる）
- 曲の題の下に書いた行は、その曲ページに出る。言葉の題と題なしの行は曲ページには出ない
- 「並べ替え」で行を別の題へ移せる
- ホームの学んだことも題ごとに並べる

指摘は曲ごとだったり「手首が固まる」のような悩みごとだったりと、何かしらの題で語られることが多いため。曲と題を別々に持たせると書くときの手間が増えるので、曲も題の1つとして扱う。

レッスンの録音中に書いた学んだことの行には、そのときの録音の経過時間を記録する。録音を止めたあとに行の時間をタップすると、レッスン録音のその位置から再生する（曲ページの先生の指摘からも同じ）。40〜50分の録音から先生の説明を探さずに済むようにするため。

学んだこと・宿題の行は、タップで編集、左スワイプで削除、「並べ替え」で順番を変えられる。

学んだこと・宿題を箇条書きにするのは、レッスン中や直後に書きやすく、ホームにもそのまま並べられるため。先生／自分を欄で分けずに行ごとの印にするのは、レッスン中に迷わず上から書けて、あとから1タップで直せるため。

個人練をレッスンの下に積み重ねるのは、宿題と見比べながら「このレッスンの後にこう練習して、こうなった」が分かるようにするため。

### 曲ページ

曲1つにつき1ページ。「まとめ」と「チャット」の2つの表示を切り替える。

**まとめ**（メイン）：種類ごとに段を分けて、俯瞰できるようにする。

- 先生の指摘：レッスンで書いた先生の指摘のうち、この曲のもの（日付ごと）
- 録音：この曲の録音の一覧
- 自分のメモ：曲ページで書いたメモと、レッスンで書いた自分の気づき（日付つきで追記）
- 扱ったレッスン

**チャット**（サブ）：メモ・録音・レッスンを日付順に1本で並べる。

- 先生の指摘は左側に先生の名前つきで表示する（相手からの発言のように）
- 自分のメモ・気づき・録音は右側に表示する
- レッスンは日付の区切りにリンクとして表示する
- 入力欄で先生／自分を切り替えて書ける

まとめをメインにするのは、録音などが一覧で固まっていた方が俯瞰しやすいため。チャットは時系列が分かりやすく記録もしやすいが、俯瞰には向かないのでサブにする。

## 録音

- アプリ内で録音できる
- 画面ロック中やほかのアプリを開いている間も録音を続ける（レッスンを丸ごと録るため。1回40〜50分程度）
- レッスンの録音中は、録音を小さくたたんでレッスンページでメモを書ける。録音中は画面上部に経過時間を出す
- 個人練は、録音を始める前に録音内容（曲）を選ぶ。練習の区切りがはっきりし、メリハリがつくため
  - 下から出るシートに「録音内容」のプルダウンと「録音開始」ボタンだけを出す。プルダウンを開いたときの選択肢の一覧は、画面の真ん中に出す
  - プルダウンには、このフォルダで前回録音した曲（前回が曲なしなら曲なし）を最初から選んでおく。まだ録音がなければ、そのレッスンで扱った最初の曲。録音を始める前に画面に出ていて、本人が確かめて「録音開始」を押すので、録音後に意図せず曲を割り振るのとは違う
  - プルダウンの中は、最近録った順の曲 → そのレッスンで扱った曲 → ほかの曲 → 曲なし（スケール・基礎練習など）→ 「＋ 曲を追加…」。曲を追加すると、その曲でそのまま録音を始める
  - ホームから録音するときは、すぐに録り始めたい。ホームから録るくらいなら前回と同じ曲のことが多いので、前回の曲を選んでおき、「録音開始」を押すだけで始められるようにする。選ぶ機会をできるだけ減らすため
- 個人練の録音中は、選んだ曲名と、宿題・その曲で学んだことを大きく表示する（練習しながら見られるように）。曲なしのときは学んだことをすべて出す
- 録音を止めたあとは一言だけを書く（曲は最初に選んでいるので選び直さない）
- 録音は「どのレッスンの後か」と「どの曲か」をそれぞれ任意で持つ
  - 個人練を録るときに曲を選ぶと、その録音はレッスンページの個人練と曲ページの両方に表示される。同じ演奏を二重に録らないため。「曲なし」で録った個人練はレッスンページにだけ出る（スケールや基礎練習など、曲を弾かない個人練もあるため）
  - 曲ページから録った録音は、既定でそのフォルダの直近のレッスン後の個人練になる（外すとレッスンと関係ない曲の録音になる）

### 録音が消えないようにする

- 録りながら少しずつ保存し、アプリが落ちたり電池が切れたりしても、そこまでの録音は残る
- 電話などで録音が止まったときは、再開すると同じ録音の続きとして録れる。経過時間も続きから数える（学んだことの行の時間がずれないように）

40〜50分のレッスンを録り直すことはできないため。

### 録音の取り込み

- ほかのアプリで録った録音（ボイスメモ、先生からもらった音源など）を、ファイルから選んで取り込める
- 取り込んだ録音も、アプリで録った録音と同じように「どのレッスンの後か」「どの曲か」を持てる（レッスン録音としても取り込める）

### 再生

- 再生速度を変えられる（0.5〜1.5倍くらい）。速度を変えても音の高さは変えない
- 5秒戻る・5秒進むのボタン
- 再生中に「付箋」をつけられる：ボタンを押すと、その位置の時間つきでメモを書ける
  - レッスン録音につけた付箋は、そのレッスンの学んだことの行になる（録音中に書いた行と同じく、時間をタップするとその位置から再生する）
  - 個人練などほかの録音につけた付箋は、その録音に付く。録音の一覧から付箋の位置へ飛べる

録音中は楽器を弾いていて手が空かないので、印をつけるのは聞き返すときにする。レッスン中にメモを書けなかった場合でも、あとで聞きながら先生の説明の位置を残せる。

## 対象外

- カラオケの点数の記録
- Notion にある既存のレッスン記録の移行
