# 要件

ボイトレ・バイオリンなどのレッスンを記録する iOS アプリ。

楽譜は前提にせず、「レッスン → 個人練 → 次のレッスン」のサイクルを記録して振り返れるようにする。

## 前提

- iOS アプリ（iPhone）
- データは端末内だけに保存する
- まずは自分用

## 画面

### ホーム

種類ごとに、直近のレッスンをカードで表示する。

- 学んだこと・宿題（箇条書き）
- そのレッスン後の個人練の回数
- 個人練を記録するボタン

「今週」ではなく「種類ごとの直近レッスン」にしているのは、バイオリンとボイトレでレッスンの頻度が違い、間隔が空いても表示が消えないようにするため。

```
┌ バイオリン（ブライアン先生）  11/16
│ 学んだこと
│ ・弓を返すときに手首を固めない
│ ・3ポジへの移動は親指を先に
│ 宿題
│ ・〇〇協奏曲 1楽章 20〜36小節
│ 個人練 2回        ［＋ 個人練を記録］
└
┌ ボイトレ  11/12
│ …
└
```

### レッスンページ

レッスン1回につき1ページ。

| 項目 | 内容 |
|---|---|
| 種類 | ユーザーが自分で追加できる（例：バイオリン（ブライアン先生）） |
| 日付 | |
| 扱った曲 | 曲ページへのリンク。複数可 |
| レッスン録音 | アプリ内で録音する |
| 学んだこと | 1行1項目の箇条書き |
| 宿題 | 1行1項目の箇条書き。チェック機能はなく、メモとして書く |
| このレッスン後の個人練 | 日付・録音・一言のセットを積み重ねる |

学んだこと・宿題を箇条書きにするのは、レッスン中や直後に書きやすく、ホームにもそのまま並べられるため。

個人練をレッスンの下に積み重ねるのは、宿題と見比べながら「このレッスンの後にこう練習して、こうなった」が分かるようにするため。

```
┌ 2026/11/16 バイオリン（ブライアン先生）
│ 扱った曲：［〇〇協奏曲］［スケール］
│
│ ▶ レッスン録音 46:12
│
│ 学んだこと
│ ・弓を返すときに手首を固めない
│ ・3ポジへの移動は親指を先に
│
│ 宿題（次回まで）
│ ・〇〇協奏曲 1楽章 20〜36小節
│
│ このレッスン後の個人練
│ 11/18  ▶ 3:20  「移動は安定してきた」
│ 11/20  ▶ 2:45  「手首はまだ固い」
│ ＋ 個人練を記録
└
```

### 曲ページ

曲1つにつき1ページ。

- メモ：日付つきで追記していく。いつ書いたメモかが分かる
- その曲を扱ったレッスンの一覧
- その曲の録音の一覧

## 録音

- アプリ内で録音できる
- 画面ロック中やほかのアプリを開いている間も録音を続ける（レッスンを丸ごと録るため。1回40〜50分程度）
- 録音は「どのレッスンの後か」と「どの曲か」をそれぞれ任意で持つ
  - 個人練を録るときに曲を選ぶと、その録音はレッスンページの個人練と曲ページの両方に表示される。同じ演奏を二重に録らないため
  - レッスンと関係ない録音は曲ページから録る

## 対象外

- カラオケの点数の記録
- Notion にある既存のレッスン記録の移行
