# 要件

ボイトレ・バイオリンなどのレッスンを記録する iOS アプリ。

楽譜は前提にせず、「レッスン → 個人練 → 次のレッスン」のサイクルを記録して振り返れるようにする。

画面の試作は `design/prototypes/`（採用案は `g1-toggle.html`）。

## 前提

- iOS アプリ（iPhone）
- データは端末内だけに保存する
- まずは自分用

## 画面

下のタブは「いま」「レッスン」「曲」の3つ。各タブの上で種類（バイオリン、ボイトレなど）を切り替える。

### いま（ホーム）

選んでいる種類の、直近のレッスンを1画面で表示する。

- 「次のレッスンまでに」：宿題を色付きの枠の中に大きく表示し、そのレッスン後の個人練の回数と最後に練習した日を添える
- 先生に言われたこと：学んだことのうち先生の指摘を3件まで
- レッスンのページへのリンク（自分の気づき・個人練の一覧はレッスンページで見る）
- 個人練スタートのボタン（画面下に固定。宿題が多くても隠れないように）

ホームは、宿題・学んだこと・個人練を同じ強さで並べると、どこを見ればいいか分からなくなる。いちばん大事な宿題だけを色付きの枠で目立たせ、ほかは控えめにする。

レッスンがまだない種類では、「最初のレッスン」ボタンを出す。

### 最初の起動と種類の管理

- 初回は、習っているもの（種類）と先生・教室を入れる画面から始める
- 種類の追加、名前と先生の変更は、画面右上の歯車から行う

「今週」ではなく「直近のレッスン」にしているのは、バイオリンとボイトレでレッスンの頻度が違い、間隔が空いても表示が消えないようにするため。

### レッスンページ

レッスン1回につき1ページ。

| 項目 | 内容 |
|---|---|
| 種類 | ユーザーが自分で追加できる（例：バイオリン（ブライアン先生）） |
| 日付 | |
| 扱った曲 | 曲ページへのリンク。複数可 |
| レッスン録音 | アプリ内で録音する |
| 学んだこと | 1行1項目の箇条書き。各行に「先生（先生の指摘）」か「自分（自分の気づき）」の印をつけ、タップで切り替える。新しい行は先生が既定 |
| 宿題 | 1行1項目の箇条書き。チェック機能はなく、メモとして書く |
| このレッスン後の個人練 | 日付・録音・一言のセットを積み重ねる |

学んだことの各行は、どの曲の話かを持つ。扱った曲が1つなら自動でその曲になる。2つ以上なら、入力欄の上の曲チップで「次に書く行の曲」を先に選んでおく。書いたあとの行は曲名をタップして選び直せる（「曲なし」なら曲ページには出ない）。

レッスンの録音中に書いた学んだことの行には、そのときの録音の経過時間を記録する。録音を止めたあとに行の時間をタップすると、レッスン録音のその位置から再生する（曲ページの先生の指摘からも同じ）。40〜50分の録音から先生の説明を探さずに済むようにするため。

学んだこと・宿題の行は、タップで編集、左スワイプで削除、「並べ替え」で順番を変えられる。

学んだこと・宿題を箇条書きにするのは、レッスン中や直後に書きやすく、ホームにもそのまま並べられるため。先生／自分を欄で分けずに行ごとの印にするのは、レッスン中に迷わず上から書けて、あとから1タップで直せるため。

個人練をレッスンの下に積み重ねるのは、宿題と見比べながら「このレッスンの後にこう練習して、こうなった」が分かるようにするため。

### 曲ページ

曲1つにつき1ページ。「まとめ」と「チャット」の2つの表示を切り替える。

**まとめ**（メイン）：種類ごとに段を分けて、俯瞰できるようにする。

- 先生の指摘：レッスンで書いた先生の指摘のうち、この曲のもの（日付ごと）
- 録音：この曲の録音の一覧
- 自分のメモ：曲ページで書いたメモと、レッスンで書いた自分の気づき（日付つきで追記）
- 扱ったレッスン

**チャット**（サブ）：メモ・録音・レッスンを日付順に1本で並べる。

- 先生の指摘は左側に先生の名前つきで表示する（相手からの発言のように）
- 自分のメモ・気づき・録音は右側に表示する
- レッスンは日付の区切りにリンクとして表示する
- 入力欄で先生／自分を切り替えて書ける

まとめをメインにするのは、録音などが一覧で固まっていた方が俯瞰しやすいため。チャットは時系列が分かりやすく記録もしやすいが、俯瞰には向かないのでサブにする。

## 録音

- アプリ内で録音できる
- 画面ロック中やほかのアプリを開いている間も録音を続ける（レッスンを丸ごと録るため。1回40〜50分程度）
- レッスンの録音中は、録音を小さくたたんでレッスンページでメモを書ける。録音中は画面上部に経過時間を出す
- 個人練の録音中は、宿題と学んだことを大きく表示する（練習しながら見られるように）
- 録音は「どのレッスンの後か」と「どの曲か」をそれぞれ任意で持つ
  - 個人練を録るときに曲を選ぶと、その録音はレッスンページの個人練と曲ページの両方に表示される。同じ演奏を二重に録らないため。曲は自動では選ばず、選ばなかった個人練はレッスンページにだけ出る（スケールや基礎練習など、曲を弾かない個人練もあるため）
  - 曲ページから録った録音は、既定でその種類の直近のレッスン後の個人練になる（外すとレッスンと関係ない曲の録音になる）

## 対象外

- カラオケの点数の記録
- Notion にある既存のレッスン記録の移行
